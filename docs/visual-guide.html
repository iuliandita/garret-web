Before this goes live

Current application releases
Downloads and platform truth

The production page will offer explicit Linux, Windows, macOS, and Android choices linked to verified release assets. It will explain alpha status and platform differences. macOS still needs native tester feedback. This guide links the current release listing; it does not invent a latest version or artifact.

The existing GitHub Pages site

Keep it live until usegarret.com is ready. Then retain a redirect and visible fallback link rather than two competing marketing sites. Update the app repository's homepage and documentation through a separate PR. Preserve useful screenshot and documentation links.

Technical foundation and cost

Proposed: a static site with Astro, native CSS, and small enhancements, hosted on Cloudflare Workers Static Assets. English and German content, light and dark themes, accessible navigation, readable HTML, canonical URLs, and a sitemap. Paid hosting is outside the budget; production deployment and DNS changes follow implementation review.

Review checkpoints

First choose the visual direction and confirm the copy and page scope. Implementation follows review. Before launch, check platform links, product claims, keyboard access, phone layouts, both languages and themes, search metadata, credits, and domain/TLS behavior.

Design exploration, not a deployed website. Screenshot and artwork credits. All product imagery comes from the real application.
