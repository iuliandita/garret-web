# Security policy

Report website vulnerabilities through [GitHub private vulnerability reporting](https://github.com/iuliandita/garret-web/security/advisories/new). Do not publish exploit details or secrets in issues. Include the affected page, source commit if known, impact and a minimal reproduction, with unrelated personal data and credentials redacted.

This policy covers this static website's source, scripts and build output. Application vulnerabilities belong in the [application's private reporting channel](https://github.com/iuliandita/garret/security/advisories/new); application bugs belong in its [issue tracker](https://github.com/iuliandita/garret/issues). Hosting account access and third-party services are outside this repository's scope.

Fixes target the current website source and published website; older snapshots have no backport commitment. There is no guaranteed response or fix window. Deployment and native application qualification are separate from website build validation.
